### Manager 403 详情
返回 Tomcat 标准 "403 Access Denied"："By default the Manager is only accessible from a browser running on the same machine"。
- 说明 Manager 应用已部署且带 `RemoteAddrValve` 回环地址限制；
- **绕过条件**：仅当存在可访问本机回环的 SSRF/代理链时才有意义，公网直连不可用；
- 未发现默认凭据可用的迹象（403 先于认证发生）。

### 目录穿越 / 编码绕过测试
`/..%2f..%2f`、`/%2e%2e/%2e%2e/`、`/..;/`、`/%c0%ae%c0%ae/` 等变体全部返回 400/404 或连接被重置（000）。
- 未发现路径穿越可利用点；
- 多个异常请求被直接断连（000），推测**前置有流量过滤设备/WAF**，会拦截明显恶意载荷（同时也说明盲目打点会被联动封禁，需谨慎）。

### Host 头虚拟主机
sxgl.lyvcct.cn / localhost / lyvcct.cn / 61.54.55.53 均返回同一默认首页，无虚拟主机区分，8088 上仅有一个默认 Host。

## 6. 建议（演练后修复方向）

1. **下线或加固 8088**：若无需对外提供服务，直接从防火墙/WAF 封禁该端口；确需使用则应隐藏默认首页、移除 docs 应用、关闭 ROOT 默认应用。
2. **升级 Tomcat**：8.5.x 已 EOL，升级到受支持的 8.5.x 最新补丁版或迁移 Tomcat 9/10/11。
3. **Manager 应用**：如不需要则删除 `manager` webapp；如需保留，保持 RemoteAddrValve 限制并改用强凭据 + 双向 TLS。
4. **确认 AJP 8009**：在授权范围内核实 8009 是否对外开放，若开放需立即处置（Ghostcat）。
5. **WAF 联动**：已观测到前置过滤设备对恶意载荷断连，建议将 8088 纳入其规则审计范围，避免误报/漏报。

## 8. 深度复测（2026-08-27 21:44-21:52）

对 8088 进行第二轮深度测试，重点验证版本 CVE 可达性、认证面与敏感文件面。**未发现新增可利用漏洞。**

### 8.1 新增测试项与结果

| 测试项 | 结果 | 结论 |
|---|---|---|
| h2c HTTP/2 升级 | 200（非 101） | **HTTP/2 未启用，CVE-2023-46589 公网不可达**（原报告"无法确认"→ 现确认不可利用） |
| WebDAV 扩展方法 | PATCH/PROPFIND/MOVE/COPY/MKCOL 全 405 | WebDAV 面关闭，CVE-2017-12615/12617 确认无面 |
| 敏感文件枚举 | 仅 /RELEASE-NOTES.txt 200，其余全 404 | 无 .git/.svn/备份/配置文件/actuator/druid/swagger 泄露 |
| Manager 认证面 | 全部 403，无 WWW-Authenticate | 403 先于认证，认证面公网不可达，默认凭据尝试无意义 |
| RemoteAddrValve 绕过 | XFF/X-Real-IP/Client-IP/Forwarded 等伪造头全 403 | Tomcat 使用真实源 IP，公网无法绕过 |
| 路径规范化 | `/%2e%2e/manager/html`、`/docs/../manager/html` → 403 | 解码规范化后能命中已部署应用，但仅受回环限制；无法读任意文件 |
| 请求走私初探 | TE+CL 不一致请求返回正常 200 | 无走私迹象；CVE-2022-42252 需前置代理链，公网直连不可利用 |
| docs 信息面量化 | /docs/api/、/docs/config/ 等子页 200 | Tomcat 官方文档，无业务敏感数据 |
| 其他 | favicon 200(size=0)；无 Set-Cookie；中文错误页泄露版本 | 纯默认 ROOT，无业务应用 |

### 8.2 关键防御特征观察

- **WAF/过滤设备规则不稳定**：`/docs/` 目录首页多次请求返回 000（偶发断连），`/..;`、`/%252f` 等恶意载荷稳定断连（000）——前置过滤对"明显恶意"与"部分目录索引"行为不一致，建议审计规则避免误拦截正常运维访问。
- 错误页（404/400）为 Tomcat 中文错误页，泄露精确版本 `Apache Tomcat/8.5.79`；响应头未显式输出 `Server`。

### 8.3 复测结论

风险评级维持 **中低**。8088 为纯默认 Tomcat 8.5.79 安装直连公网，无业务应用、无新增可利用面；主要风险仍是版本 EOL（8.5.79，2024-03 停止支持）与默认组件暴露。修复优先级不变：封禁端口或加固升级。
